# Degree-Project
Repository to develop the degree project

## Project Structure

This degree project is organized into three main components:

### 📱 [Mobile App](./mobile-app/)
The mobile application that provides the user interface for interacting with the system, including data visualization, device control, and configuration management.

### 🔧 [Microcontroller](./microcontroller/)
The firmware and software for the microcontroller that handles sensor data collection, communication protocols, and hardware control.

### ⚡ [Hardware Circuits](./hardware-circuits/)
The hardware design, circuit schematics, and physical components that form the foundation of the system's data acquisition and control capabilities.

## Getting Started

Each component has its own dedicated folder with detailed documentation. Please refer to the README file in each folder for specific setup and development instructions.
