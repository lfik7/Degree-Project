# Folder to add images about the circuits

This folder contains images related to the circuits used and developed in this degree project.

## How to use

- Save all images (e.g., photos, diagrams, screenshots) of your circuits in this folder.
- Give each image a descriptive name, such as `amplifier-v1.png`, `final-board.jpg`, etc.
- Reference images in your documentation or reports using the relative path, for example:  
  `![Amplifier Circuit](circuit-images/amplifier-v1.png)`

## Example

- `amplifier-v1.png` — Schematic of the version 1 amplifier circuit.
- `final-board.jpg` — Photo of the final assembled circuit board.
