# Folfer to store the PCB files about desing
This folder contains schematic and PCB files related to the circuits used and developed in this degree project.

## How to use
Save all chematic and PCB files (e.g., Alimentacion, Sensores, etc) of your circuits in this folder.
Give each image a descriptive name, such as CircuitDriver_power_V2_PWM.asc, etc.
## Example
ESP32WROOM_sheet.SchDoc — Fila that contains the schematic of the ESP32WROOM used in the PCB.
