# Hardware Circuits

## Objective

This folder contains the hardware design, circuit schematics, and physical components documentation for the degree project. This includes:

- Circuit schematics and PCB designs
- Component specifications and datasheets
- Hardware assembly instructions
- Sensor and actuator integration guides
- Power supply design and management
- Physical enclosure and mounting solutions
- Testing and calibration procedures

## Development

The hardware circuits are designed to work in conjunction with the microcontroller firmware to provide reliable data acquisition and control capabilities for the overall system.

## Getting Started

Documentation for building, assembling, and testing the hardware components will be added here as development progresses.
