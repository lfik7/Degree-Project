# Folder to add schematic files about the circuits
This folder contains schematic files related to the circuits used and developed in this degree project.

## How to use
Save all chematic files (e.g., power driver, LOD's, etc) of your circuits in this folder.
Give each image a descriptive name, such as CircuitDriver_power_V2_PWM.asc, etc.
## Example
CircuitDriver_power_PWM.asc — Schematic of the version 1 PWM driver.
