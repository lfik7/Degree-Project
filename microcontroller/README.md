# Microcontroller

## Objective

This folder contains the firmware and software for the microcontroller component of the degree project. The microcontroller acts as the bridge between the hardware sensors/actuators and the mobile application, providing:

- Sensor data collection and processing
- Communication with mobile app via WiFi/Bluetooth
- Control of connected hardware components
- Real-time system monitoring
- Data buffering and transmission protocols
- Power management and optimization

## Development

The microcontroller firmware is designed to be efficient, reliable, and easily maintainable while providing seamless integration with both the hardware circuits and mobile app components.
