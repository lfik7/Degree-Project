# Mobile App

## Objective

This folder contains the mobile application component of the degree project. The mobile app serves as the user interface for interacting with the system, providing features such as:

- User authentication and management
- Real-time data visualization
- Control interface for connected devices
- Data logging and history viewing
- Settings and configuration management

## Development

The mobile app is designed to work seamlessly with the microcontroller and hardware components to provide a complete IoT solution.
